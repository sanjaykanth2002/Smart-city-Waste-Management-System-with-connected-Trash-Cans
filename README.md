# 🏙️ Smart City Waste Management System with Connected Trashcans

An IoT-based waste management solution designed to improve urban cleanliness and efficiency through real-time monitoring and data analysis.

🎥 **Project Demo:** [▶️ Watch on YouTube](https://youtu.be/_VQWUIA6jrA)

---

## 🚀 Features
- 🗑️ Smart bins with sensor-based waste level monitoring  
- 📡 Real-time data transmission to cloud platforms  
- 🧭 Optimized collection routes to reduce overflow incidents  
- 📊 Centralized dashboard for analysis and management
